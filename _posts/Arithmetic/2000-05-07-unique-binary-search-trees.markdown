[96. 不同的二叉搜索树](https://leetcode.cn/problems/unique-binary-search-trees)

### 题目描述

给定一个整数 `n`，返回由 `n` 个节点组成的不同的二叉搜索树（BST）的个数。

### 示例

#### 示例 1:
```
输入: n = 3
输出: 5
解释:
给定 n = 3, 共 5 种不同的二叉搜索树:
  1         3     3      2      1
   \       /     /      / \      \
    3     2     1      1   3      2
   /     /       \                 \
  2     1         2                 3
```

#### 示例 2:
```
输入: n = 1
输出: 1
```

### 提示
- `1 <= n <= 19`

### 解题思路

本题属于经典的动态规划（DP）问题，求解的是不同的二叉搜索树的个数。我们可以通过以下的思路来解决问题：

1. **二叉搜索树的性质**：二叉搜索树（BST）有一个重要的性质：对于一个根节点，左子树的节点值都比根节点小，右子树的节点值都比根节点大。通过这个性质，可以将一个区间 `[1, n]` 分为左子树和右子树，其中每个数字都可以作为根节点，根节点左边的数字构成左子树，右边的数字构成右子树。

2. **递归求解**：假设我们选择某个数字 `i` 作为根节点，那么 `i` 的左子树是从 `1` 到 `i-1` 的节点，右子树是从 `i+1` 到 `n` 的节点。对于左子树和右子树的构建，可以递归地计算其对应的二叉搜索树的个数。

3. **动态规划（DP）**：假设 `dp[i]` 表示由 `i` 个节点构成的不同二叉搜索树的个数。我们可以得到递推关系式：
   - 对于每一个节点 `i`，它可以作为根节点，左子树的节点数为 `i-1`，右子树的节点数为 `n-i`，所以对于根节点 `i`，可以将其左子树和右子树的结果相乘。
   - 公式为：`dp[n] = Σ(dp[i-1] * dp[n-i])`，其中 `i` 从 `1` 到 `n`。

4. **边界条件**：`dp[0] = 1` 和 `dp[1] = 1`。这意味着，0 个节点的二叉搜索树有 1 种方式（即空树），1 个节点的二叉搜索树也只有 1 种方式。

### C语言实现

```c
#include <stdio.h>

// 计算由 n 个节点组成的不同二叉搜索树的个数
int numTrees(int n) {
    // 动态规划数组，dp[i] 表示 i 个节点的不同二叉搜索树的个数
    int dp[n+1];
    // 初始化 dp 数组
    dp[0] = 1;  // 空树的个数为 1
    dp[1] = 1;  // 只有一个节点的树有 1 种方式

    // 从 2 到 n，计算每个节点数对应的二叉搜索树个数
    for (int i = 2; i <= n; i++) {
        dp[i] = 0;  // 初始化 dp[i]
        // 通过循环计算所有根节点 i 的情况
        for (int j = 1; j <= i; j++) {
            dp[i] += dp[j-1] * dp[i-j];  // 左子树为 j-1，右子树为 i-j
        }
    }

    // 返回由 n 个节点组成的二叉搜索树的个数
    return dp[n];
}

int main() {
    int n = 3;
    printf("Number of unique BSTs with %d nodes: %d\n", n, numTrees(n));
    return 0;
}
```

### C++实现

```cpp
#include <iostream>
#include <vector>
using namespace std;

class Solution {
public:
    // 计算由 n 个节点组成的不同二叉搜索树的个数
    int numTrees(int n) {
        // 动态规划数组，dp[i] 表示 i 个节点的不同二叉搜索树的个数
        vector<int> dp(n + 1, 0);
        
        // 初始化边界条件
        dp[0] = 1;  // 空树的个数为 1
        dp[1] = 1;  // 只有一个节点的树有 1 种方式

        // 从 2 到 n，计算每个节点数对应的二叉搜索树个数
        for (int i = 2; i <= n; i++) {
            // 遍历每个根节点 i
            for (int j = 1; j <= i; j++) {
                dp[i] += dp[j - 1] * dp[i - j];  // 左子树为 j-1，右子树为 i-j
            }
        }

        // 返回由 n 个节点组成的二叉搜索树的个数
        return dp[n];
    }
};

int main() {
    Solution sol;
    int n = 3;
    cout << "Number of unique BSTs with " << n << " nodes: " << sol.numTrees(n) << endl;
    return 0;
}
```

### 代码说明

#### C语言版本

- 使用一个数组 `dp` 来存储每个节点数下不同二叉搜索树的数量。`dp[i]` 表示使用 `i` 个节点的二叉搜索树的数量。
- 初始值 `dp[0] = 1` 和 `dp[1] = 1`。
- 对于每个节点数 `i`，通过累加每个可能的根节点 `j` 来更新 `dp[i]`，其递推公式为 `dp[i] += dp[j-1] * dp[i-j]`。

#### C++版本

- C++ 中使用 `vector<int>` 来表示动态规划数组，方便扩展和管理。
- 类 `Solution` 中的方法 `numTrees` 计算并返回不同二叉搜索树的个数。
- `main` 函数实例化 `Solution` 类并调用 `numTrees` 方法。

### 时间和空间复杂度

- **时间复杂度**：O(n^2)，因为我们有两个嵌套的循环，外层循环从 2 到 n，内层循环从 1 到 i。
- **空间复杂度**：O(n)，因为我们使用了一个大小为 n+1 的数组来存储结果。
