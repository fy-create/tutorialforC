[62. 不同路径](https://leetcode.cn/problems/unique-paths)

### 题目要求

**题目名称**: 不同路径

**题目描述**:  
一个机器人位于一个 `m x n` 的网格的左上角（起始点 `(0, 0)`）。机器人每次只能向下或者向右移动一步。机器人试图到达网格的右下角（终点 `(m-1, n-1)`）。  
问有多少条不同的路径？

**输入**:  
- 一个整数 `m`，表示网格的行数。
- 一个整数 `n`，表示网格的列数。

**输出**:  
- 返回从左上角到右下角的不同路径数。

**示例 1**:  
输入:  
`m = 3, n = 7`  
输出:  
`28`

**示例 2**:  
输入:  
`m = 3, n = 2`  
输出:  
`3`  
解释:  
从左上角到右下角的路径为：  
1. 向右，向右，向下，向下  
2. 向右，向下，向右，向下  
3. 向下，向右，向右，向下

**提示**:  
- `1 <= m, n <= 100`  
- 题目数据保证答案小于等于 `2 * 10^9`。

### 解题思路

1. **动态规划的思路**:
   - 这个问题可以使用动态规划来求解。
   - 设 `dp[i][j]` 表示到达位置 `(i, j)` 的不同路径的数量。
   - 初始化：`dp[0][0] = 1`，因为起始点到起始点的路径数是 1。
   - 对于任意位置 `(i, j)`，可以从位置 `(i-1, j)` 或者 `(i, j-1)` 到达该位置，因此：
     ```
     dp[i][j] = dp[i-1][j] + dp[i][j-1]
     ```
     - `dp[i-1][j]` 表示从上面到达该点的路径数；
     - `dp[i][j-1]` 表示从左边到达该点的路径数。
   - 边界条件：第一行的每个位置只能从左边到达，第一列的每个位置只能从上边到达。

2. **空间优化**:
   - 使用二维数组来存储 `dp` 表，可以优化空间。我们可以只使用一维数组，因为每一行的 `dp` 只依赖于当前行和上一行的值。
   - 只需要一个长度为 `n` 的一维数组即可，逐行更新。

3. **时间复杂度**:
   - 时间复杂度为 O(m * n)，因为我们需要遍历整个 `m x n` 的网格。
   - 空间复杂度为 O(n)，因为我们只需要一个长度为 `n` 的一维数组来存储当前行的状态。

### C 语言解答

```c
#include <stdio.h>
#include <stdlib.h>

// 求解不同路径数的函数
int uniquePaths(int m, int n) {
    // 创建一个长度为n的一维数组，存储当前行的路径数
    int* dp = (int*)malloc(sizeof(int) * n);

    // 初始化第一行的所有位置为1
    for (int i = 0; i < n; i++) {
        dp[i] = 1;
    }

    // 从第二行开始进行动态规划
    for (int i = 1; i < m; i++) {
        // 每一行的第一个位置路径数为1
        dp[0] = 1;
        for (int j = 1; j < n; j++) {
            // 更新当前格子的路径数
            dp[j] += dp[j - 1];
        }
    }

    // 返回最后一个位置的路径数
    int result = dp[n - 1];
    free(dp);  // 释放动态分配的内存
    return result;
}

int main() {
    int m = 3, n = 7;
    printf("Unique paths: %d\n", uniquePaths(m, n));
    return 0;
}
```

### C++ 语言解答

```cpp
#include <iostream>
#include <vector>

using namespace std;

class Solution {
public:
    // 求解不同路径数的函数
    int uniquePaths(int m, int n) {
        // 创建一个长度为n的一维数组，存储当前行的路径数
        vector<int> dp(n, 1);  // 初始化第一行所有位置的路径数为1

        // 从第二行开始进行动态规划
        for (int i = 1; i < m; i++) {
            // 每一行的第一个位置路径数为1
            for (int j = 1; j < n; j++) {
                // 更新当前格子的路径数
                dp[j] += dp[j - 1];
            }
        }

        // 返回最后一个位置的路径数
        return dp[n - 1];
    }
};

int main() {
    Solution solution;
    int m = 3, n = 7;
    cout << "Unique paths: " << solution.uniquePaths(m, n) << endl;
    return 0;
}
```

### 说明

1. **C语言解答**:
   - 我们使用一个一维数组 `dp` 来存储当前行的路径数，初始化为全 `1`，表示第一行的路径数为 `1`。
   - 然后通过双层循环，更新每个位置的路径数。内层循环更新当前位置 `dp[j]`，它的值等于上方 `dp[j]` 和左方 `dp[j-1]` 之和。
   - 最后返回 `dp[n-1]`，即右下角的路径数。

2. **C++解答**:
   - 与 C 语言解法类似，但我们使用 `vector<int>` 来存储 `dp` 数组，初始化为 `1`，表示第一行的路径数为 `1`。
   - 使用类似的动态规划思路，逐行更新 `dp` 数组中的路径数。

3. **空间优化**:
   - 使用一维数组代替二维数组，通过逐行更新，节省了空间。

两种解法都实现了动态规划，解决了路径数的计算问题，且时间复杂度为 O(m * n)，空间复杂度为 O(n)。
