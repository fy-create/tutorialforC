[36. 有效的数独](https://leetcode.cn/problems/valid-sudoku)

## 题目要求

验证一个数独是否有效。

数独的规则如下：
- 数字 1-9 在每行只能出现一次。
- 数字 1-9 在每列只能出现一次。
- 数字 1-9 在每个 3x3 宫内只能出现一次。

给定一个 `9x9` 的二维字符数组 `board`，其中每个字符是一个数字（'1' - '9'）或一个空白字符('.')，你需要判断数独是否有效。数独是有效的，若：
- 数字 1-9 在每行只能出现一次。
- 数字 1-9 在每列只能出现一次。
- 数字 1-9 在每个 3x3 宫内只能出现一次。

board = [

### 提示:
- board.length == 9
- board[i].length == 9
- board[i][j] 为 '1' 到 '9' 或 '.'。

## 解题思路

为了验证数独的有效性，需要确保数独的三个主要规则：
1. **行检查**：每行中的数字不能重复。
2. **列检查**：每列中的数字不能重复。
3. **3x3宫检查**：每个 3x3 的小宫格中的数字不能重复。

### 解题方法：
1. **行检查**：
   - 对每一行遍历，检查数字是否重复。如果当前数字已出现过，则无效。

2. **列检查**：
   - 对每一列遍历，检查数字是否重复。类似行检查，如果当前数字已出现过，则无效。

3. **3x3宫格检查**：
   - 对每个 3x3 宫格进行检查。可以通过以下公式找到宫格的起始位置：
     - 宫格的行索引范围是 `[i // 3 * 3, i // 3 * 3 + 3]`
     - 宫格的列索引范围是 `[j // 3 * 3, j // 3 * 3 + 3]`
   - 如果当前数字已出现过，则无效。

4. **使用哈希集合**：
   - 使用哈希集合（`set`）来记录已经出现的数字。对于行、列和宫格的检查，我们分别使用三个集合来记录。

### C语言解法

```c
#include <stdio.h>
#include <stdbool.h>

// 判断数独是否有效
bool isValidSudoku(char** board, int boardSize, int* boardColSize) {
    // 用于存储行、列和宫格的数字集合
    bool rows[9][9] = {0};  // rows[i][j]表示第i行是否已经出现过数字j+1
    bool cols[9][9] = {0};  // cols[i][j]表示第i列是否已经出现过数字j+1
    bool boxes[9][9] = {0}; // boxes[i][j]表示第i个3x3宫格是否已经出现过数字j+1

    for (int i = 0; i < 9; i++) {
        for (int j = 0; j < 9; j++) {
            if (board[i][j] != '.') {
                int num = board[i][j] - '1';  // 将字符转为数字
                int boxIndex = (i / 3) * 3 + (j / 3);  // 计算3x3宫格的索引

                // 检查行、列和宫格中是否出现过该数字
                if (rows[i][num] || cols[j][num] || boxes[boxIndex][num]) {
                    return false;  // 如果有重复，返回false
                }

                // 标记该数字在行、列和宫格中出现
                rows[i][num] = true;
                cols[j][num] = true;
                boxes[boxIndex][num] = true;
            }
        }
    }
    return true;  // 没有重复，返回true
}

int main() {
    // 数独棋盘
    char* board[9] = {
        "53..7....",
        "6..195...",
        ".98....6.",
        "8...6...3",
        "4..8.3..1",
        "7...2...6",
        ".6....28.",
        "..4.1.9..",
        "...8..79."
    };
    int boardColSize[9] = {9, 9, 9, 9, 9, 9, 9, 9, 9};
    printf("%s\n", isValidSudoku(board, 9, boardColSize) ? "true" : "false");
    return 0;
}
```

### C++ 解法

C++ 中我们可以使用 STL 容器（如 `set` 或 `vector`）来简化代码，同时采用更简洁的语法。

```cpp
#include <iostream>
#include <vector>
#include <unordered_set>
using namespace std;

class Solution {
public:
    bool isValidSudoku(vector<vector<char>>& board) {
        // 用于存储行、列和宫格的数字集合
        vector<unordered_set<char>> rows(9), cols(9), boxes(9);

        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                char num = board[i][j];
                if (num != '.') {
                    int boxIndex = (i / 3) * 3 + (j / 3);  // 计算3x3宫格的索引

                    // 检查当前数字是否已在行、列或宫格中出现
                    if (rows[i].count(num) || cols[j].count(num) || boxes[boxIndex].count(num)) {
                        return false;
                    }

                    // 标记当前数字在行、列和宫格中
                    rows[i].insert(num);
                    cols[j].insert(num);
                    boxes[boxIndex].insert(num);
                }
            }
        }

        return true;  // 没有重复，返回true
    }
};

int main() {
    Solution solution;
    vector<vector<char>> board = {
        {'5','3','.','.','7','.','.','.','.'},
        {'6','.','.','1','9','5','.','.','.'},
        {'.','9','8','.','.','.','.','6','.'},
        {'8','.','.','.','6','.','.','.','3'},
        {'4','.','.','8','.','3','.','.','1'},
        {'7','.','.','.','2','.','.','.','6'},
        {'.','6','.','.','.','.','2','8','.'},
        {'.','.','.','4','1','9','.','.','5'},
        {'.','.','.','.','8','.','.','7','9'}
    };

    cout << (solution.isValidSudoku(board) ? "true" : "false") << endl;

    return 0;
}
```

### 代码解析

#### C语言代码解析：
- 使用 `rows`、`cols` 和 `boxes` 数组来标记每行、每列和每个 3x3 宫格中数字的出现情况。
- 通过 `rows[i][num]`、`cols[j][num]` 和 `boxes[boxIndex][num]` 来记录当前数字是否已经出现过。
- 如果有重复数字，则返回 `false`，否则返回 `true`。

#### C++ 代码解析：
- 使用 `unordered_set` 来存储每行、每列和每个 3x3 宫

格中已经出现的数字。
- 对于每个数字，检查它在行、列和宫格中的出现情况，如果有重复，返回 `false`，否则返回 `true`。

### 时间复杂度：
- **时间复杂度：** O(81) = O(1)，因为我们只需要遍历 9x9 的棋盘，每个格子最多检查一次。
  
- **空间复杂度：** O(81) = O(1)，因为我们只需要为行、列和宫格的数字使用常数级别的额外空间。

### 总结：
- 本题的关键是利用哈希集合或者数组来标记行、列和宫格的数字，从而有效地检查数独是否符合规则。
- C++ 中使用 STL 容器 `unordered_set` 可以让代码更简洁，避免手动管理数组的大小。
