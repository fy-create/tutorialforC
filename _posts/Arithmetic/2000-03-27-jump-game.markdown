[55. 跳跃游戏](https://leetcode.cn/problems/jump-game)

## 题目要求

### 描述：
给定一个非负整数数组 `nums`，你最初位于数组的第一个位置。数组中的每个元素代表你在该位置可以跳跃的最大长度。判断你是否能够到达最后一个位置。

**示例 1：**
```text
输入：nums = [2,3,1,1,4]
输出：true
解释：从索引 0 出发，2 可以跳到 2 或者 3。跳到 3 后，3 可以跳到 4，最终到达最后一个位置。
```

**示例 2：**
```text
输入：nums = [3,2,1,0,4]
输出：false
解释：从索引 0 出发，你最多能跳到索引 3 。但无法再跳跃到最后一个位置。
```

### 提示：
- 1 <= nums.length <= 10^4
- 0 <= nums[i] <= 10^5

## 解题思路

### 1. **问题分析：**
   - 我们需要判断是否能够通过跳跃从数组的第一个位置到达最后一个位置。
   - 每个元素的值代表从该位置可以跳跃的最大步数。

### 2. **优化思路：**
   - 使用贪心算法：我们从左到右遍历数组，每次跳跃的最大范围可以更新。如果当前索引能够跳跃到某个位置，并且此位置可以达到更远的范围，那么就继续跳跃。每次跳跃后更新最大的可到达索引。
   - **状态定义**：`maxReach` 表示当前能够到达的最远位置。如果某一时刻 `maxReach` 达到了最后一个位置，返回 `true`。
   - 如果遍历结束后 `maxReach` 仍然小于最后一个位置，则返回 `false`。

### 3. **解法过程：**
   - 从第一个位置开始，记录当前能够到达的最远位置。
   - 遍历数组，如果当前索引大于 `maxReach`，说明无法再继续跳跃，返回 `false`。
   - 如果遍历过程中 `maxReach` 达到了数组的末尾，返回 `true`。

### 4. **时间复杂度与空间复杂度：**
   - **时间复杂度**：O(n)，只需要遍历数组一次。
   - **空间复杂度**：O(1)，使用常数空间。

## C语言解答

```c
#include <stdio.h>
#include <stdbool.h>

bool canJump(int* nums, int numsSize) {
    // 初始化当前能够到达的最远位置
    int maxReach = 0;

    // 遍历数组
    for (int i = 0; i < numsSize; i++) {
        // 如果当前位置超过了当前能够到达的最远位置，说明无法到达当前位置，返回 false
        if (i > maxReach) {
            return false;
        }
        
        // 更新最远位置
        maxReach = (i + nums[i]) > maxReach ? (i + nums[i]) : maxReach;

        // 如果已经能够到达最后一个位置，直接返回 true
        if (maxReach >= numsSize - 1) {
            return true;
        }
    }

    // 如果遍历完数组后仍然无法到达最后一个位置，返回 false
    return false;
}

int main() {
    int nums[] = {2, 3, 1, 1, 4};
    int numsSize = sizeof(nums) / sizeof(nums[0]);

    if (canJump(nums, numsSize)) {
        printf("Can reach the last position.\n");
    } else {
        printf("Cannot reach the last position.\n");
    }
    
    return 0;
}
```

## C++解答

```cpp
#include <iostream>
#include <vector>
using namespace std;

class Solution {
public:
    bool canJump(vector<int>& nums) {
        // 初始化当前能够到达的最远位置
        int maxReach = 0;

        // 遍历数组
        for (int i = 0; i < nums.size(); i++) {
            // 如果当前位置超过了当前能够到达的最远位置，说明无法到达当前位置，返回 false
            if (i > maxReach) {
                return false;
            }
            
            // 更新最远位置
            maxReach = max(maxReach, i + nums[i]);

            // 如果已经能够到达最后一个位置，直接返回 true
            if (maxReach >= nums.size() - 1) {
                return true;
            }
        }

        // 如果遍历完数组后仍然无法到达最后一个位置，返回 false
        return false;
    }
};

int main() {
    Solution solution;
    vector<int> nums = {2, 3, 1, 1, 4};

    if (solution.canJump(nums)) {
        cout << "Can reach the last position." << endl;
    } else {
        cout << "Cannot reach the last position." << endl;
    }

    return 0;
}
```

### 代码解析

#### C语言解答：
1. **变量初始化：**
   - `maxReach`：表示当前能够到达的最远位置。初始化为 0，因为一开始只能站在第一个位置。
   
2. **遍历数组：**
   - 在遍历每个位置时，检查当前索引 `i` 是否已经超过了 `maxReach`。如果超过，则返回 `false`，因为无法从当前位置跳跃。
   
3. **更新 `maxReach`：**
   - 每遍历一个位置，更新 `maxReach` 为 `i + nums[i]` 和当前 `maxReach` 的最大值。

4. **提前结束：**
   - 如果在某一时刻，`maxReach` 已经大于或等于最后一个位置，则可以提前返回 `true`。

5. **输出结果：**
   - 如果遍历结束后 `maxReach` 小于最后一个位置，返回 `false`。

#### C++ 解答：
1. **类结构：**
   - `Solution` 类封装了 `canJump` 函数，方便调用。

2. **使用 `max` 函数：**
   - 在 C++ 中使用 `std::max` 来计算最大值，简化了代码的编写。

3. **其他逻辑与 C 语言版本相同。**

### 时间复杂度与空间复杂度：
- **时间复杂度：** O(n)，每个元素仅遍历一次。
- **空间复杂度：** O(1)，只用了常数级别的额外空间。

### 小结：
- 通过贪心算法，问题的时间复杂度降到了 O(n)，并且空间复杂度为 O(1)，这是一个非常高效的解法。
