[275. H 指数 II](https://leetcode.cn/problems/h-index-ii)

### 题目描述

给定一个按非递减顺序排列的整数数组 `citations`，其中 `citations[i]` 表示研究者的第 `i` 篇论文被引用的次数。计算并返回该研究者的 **h 指数**。

**h 指数**的定义：h 代表“高引用次数”（high citations），一名科研人员的 h 指数是指他（她）的 `n` 篇论文中总共有 `h` 篇论文分别被引用了至少 `h` 次，且其余的 `n - h` 篇论文每篇被引用次数不超过 `h` 次。

**注意：**
- 如果 `h` 有多种可能的值，`h` 指数是其中最大的那个。
- 你必须设计时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1:**

```
输入: citations = [0,1,3,5,6]
输出: 3
解释: 
给定数组表示研究者总共有 5 篇论文，每篇论文相应的被引用了 0, 1, 3, 5, 6 次。
由于研究者有 3 篇论文每篇被引用了至少 3 次，其余两篇论文每篇被引用次数不超过 3 次，所以她的 h 指数是 3。
```

**示例 2:**

```
输入: citations = [1,2,100]
输出: 2
解释: 
给定数组表示研究者总共有 3 篇论文，每篇论文相应的被引用了 1, 2, 100 次。
由于研究者有 2 篇论文每篇被引用了至少 2 次，其余一篇论文被引用次数不超过 2 次，所以她的 h 指数是 2。
```

**提示：**
- `n == citations.length`
- `1 <= n <= 10^5`
- `0 <= citations[i] <= 1000`
- `citations` 按 **非递减顺序** 排列

---

### 解题思路

由于数组 `citations` 已经按非递减顺序排列，我们可以利用二分查找来高效地找到 h 指数。

1. **二分查找的核心思想：**
   - 定义 `left` 和 `right` 分别指向数组的起始和末尾。
   - 计算中间位置 `mid`，并检查 `citations[mid]` 是否满足 `citations[mid] >= n - mid`。
   - 如果满足，说明至少有 `n - mid` 篇论文被引用了至少 `citations[mid]` 次，尝试缩小范围到左半部分。
   - 如果不满足，说明需要更多的论文满足条件，尝试缩小范围到右半部分。

2. **终止条件：**
   - 当 `left` 和 `right` 相遇时，返回 `n - left` 作为 h 指数。

---

### C 语言解答

```c
#include <stdio.h>

// 函数原型
int hIndex(int* citations, int citationsSize);

// 实现函数
int hIndex(int* citations, int citationsSize) {
    int left = 0, right = citationsSize - 1;
    int n = citationsSize;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        // 检查 citations[mid] 是否满足条件
        if (citations[mid] >= n - mid) {
            right = mid - 1; // 尝试缩小范围到左半部分
        } else {
            left = mid + 1; // 尝试缩小范围到右半部分
        }
    }

    // h 指数为 n - left
    return n - left;
}

// 测试代码
int main() {
    int citations[] = {0, 1, 3, 5, 6};
    int citationsSize = sizeof(citations) / sizeof(citations[0]);

    int result = hIndex(citations, citationsSize);
    printf("h 指数: %d\n", result);

    return 0;
}
```

### C++ 解答

```cpp
#include <iostream>
#include <vector>
using namespace std;

class Solution {
public:
    int hIndex(vector<int>& citations) {
        int left = 0, right = citations.size() - 1;
        int n = citations.size();

        while (left <= right) {
            int mid = left + (right - left) / 2;

            // 检查 citations[mid] 是否满足条件
            if (citations[mid] >= n - mid) {
                right = mid - 1; // 尝试缩小范围到左半部分
            } else {
                left = mid + 1; // 尝试缩小范围到右半部分
            }
        }

        // h 指数为 n - left
        return n - left;
    }
};

// 测试代码
int main() {
    vector<int> citations = {0, 1, 3, 5, 6};
    Solution solution;
    int result = solution.hIndex(citations);

    cout << "h 指数: " << result << endl;

    return 0;
}
```
