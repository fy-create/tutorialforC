[148. 排序链表](https://leetcode.cn/problems/sort-list)

### 题目描述

**排序链表**

给定一个链表的头节点 `head`，请将该链表按升序排序并返回排序后的链表。

要求：
- 你必须在 O(n log n) 的时间复杂度下完成排序。

**示例 1:**

```
输入: head = [4,2,1,3]
输出: [1,2,3,4]
```

**示例 2:**

```
输入: head = [-1,5,3,4,0]
输出: [-1,0,3,4,5]
```

**提示:**

- 链表中的节点数在 [1, 5000] 范围内。
- `-5000 <= Node.val <= 5000`

---

### 解题思路

这道题要求我们对链表进行排序，并且给定了时间复杂度要求 O(n log n)。针对这个要求，我们可以选择 **归并排序**。

#### 归并排序的原理

归并排序是一种分治算法，通常有以下步骤：
1. 将数据分成两半；
2. 对每一半数据递归地进行排序；
3. 合并两个已排序的数据部分。

对于链表而言，归并排序特别适合，因为我们可以在链表中使用指针来分割数据，递归地进行排序，并且通过合并两个已排序的链表来完成排序操作。

#### 归并排序的链表实现

1. **分割链表**：我们可以使用快慢指针来找到链表的中间节点。快指针每次移动两步，慢指针每次移动一步。这样，当快指针到达链表末尾时，慢指针刚好指向中间节点。
2. **递归排序**：将链表从中间节点分割成两部分，分别递归地排序每一部分。
3. **合并两个已排序的链表**：合并两个有序的链表，生成一个新的有序链表。

#### 算法步骤

1. **找中点**：通过快慢指针找出链表的中间节点。
2. **分割链表**：将链表从中间断开，得到两部分。
3. **递归排序**：对两部分分别进行归并排序。
4. **合并链表**：合并两个已排序的链表。

### C语言解答

```c
#include <stdio.h>
#include <stdlib.h>

// 链表节点定义
struct ListNode {
    int val;
    struct ListNode *next;
    struct ListNode(int x) : val(x), next(NULL) {}
};

// 合并两个有序链表
struct ListNode* merge(struct ListNode* l1, struct ListNode* l2) {
    struct ListNode *dummyHead = (struct ListNode*)malloc(sizeof(struct ListNode));
    struct ListNode *cur = dummyHead;
    
    while (l1 != NULL && l2 != NULL) {
        if (l1->val < l2->val) {
            cur->next = l1;
            l1 = l1->next;
        } else {
            cur->next = l2;
            l2 = l2->next;
        }
        cur = cur->next;
    }
    
    if (l1 != NULL) {
        cur->next = l1;
    }
    if (l2 != NULL) {
        cur->next = l2;
    }
    
    return dummyHead->next;
}

// 找到链表的中间节点
struct ListNode* findMiddle(struct ListNode* head) {
    struct ListNode *slow = head;
    struct ListNode *fast = head;
    
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
    }
    
    return slow;
}

// 归并排序链表
struct ListNode* sortList(struct ListNode* head) {
    if (head == NULL || head->next == NULL) return head;
    
    struct ListNode* middle = findMiddle(head);
    struct ListNode* right = middle->next;
    middle->next = NULL;
    
    struct ListNode* left = sortList(head);
    right = sortList(right);
    
    return merge(left, right);
}

// 打印链表
void printList(struct ListNode* head) {
    struct ListNode* current = head;
    while (current != NULL) {
        printf("%d -> ", current->val);
        current = current->next;
    }
    printf("NULL\n");
}

// 主函数示例
int main() {
    // 创建链表 [4, 2, 1, 3]
    struct ListNode *head = (struct ListNode*)malloc(sizeof(struct ListNode));
    head->val = 4;
    head->next = (struct ListNode*)malloc(sizeof(struct ListNode));
    head->next->val = 2;
    head->next->next = (struct ListNode*)malloc(sizeof(struct ListNode));
    head->next->next->val = 1;
    head->next->next->next = (struct ListNode*)malloc(sizeof(struct ListNode));
    head->next->next->next->val = 3;
    head->next->next->next->next = NULL;
    
    printf("Before sorting: ");
    printList(head);
    
    struct ListNode* sortedHead = sortList(head);
    
    printf("After sorting: ");
    printList(sortedHead);

    return 0;
}
```

### C++ 解答

```cpp
#include <iostream>
using namespace std;

// 链表节点定义
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(NULL) {}
};

class Solution {
public:
    // 合并两个有序链表
    ListNode* merge(ListNode* l1, ListNode* l2) {
        ListNode* dummyHead = new ListNode(0);
        ListNode* cur = dummyHead;
        
        while (l1 != NULL && l2 != NULL) {
            if (l1->val < l2->val) {
                cur->next = l1;
                l1 = l1->next;
            } else {
                cur->next = l2;
                l2 = l2->next;
            }
            cur = cur->next;
        }
        
        if (l1 != NULL) {
            cur->next = l1;
        }
        if (l2 != NULL) {
            cur->next = l2;
        }
        
        return dummyHead->next;
    }

    // 找到链表的中间节点
    ListNode* findMiddle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        
        while (fast != NULL && fast->next != NULL) {
            slow = slow->next;
            fast = fast->next->next;
        }
        
        return slow;
    }

    // 归并排序链表
    ListNode* sortList(ListNode* head) {
        if (head == NULL || head->next == NULL) return head;
        
        ListNode* middle = findMiddle(head);
        ListNode* right = middle->next;
        middle->next = NULL;
        
        ListNode* left = sortList(head);
        right = sortList(right);
        
        return merge(left, right);
    }

    // 打印链表
    void printList(ListNode* head) {
        ListNode* current = head;
        while (current != NULL) {
            cout << current->val << " -> ";
            current = current->next;
        }
        cout << "NULL" << endl;
    }
};

int main() {
    // 创建链表 [4, 2, 1, 3]
    ListNode* head = new ListNode(4);
    head->next = new ListNode(2);
    head->next->next = new ListNode(1);
    head->next->next->next = new ListNode(3);

    Solution sol;
    
    cout << "Before sorting: ";
    sol.printList(head);
    
    ListNode* sortedHead = sol.sortList(head);
    
    cout << "After sorting: ";
    sol.printList(sortedHead);

    return 0;
}
```

### 关键点说明

1. **归并排序**：归并排序适合链表，因为它可以递归地分割链表，且在合并两个链表时，能够保持 O(n log n) 的时间复杂度。
2. **找中点**：使用快慢指针法找到链表的中点，这样可以将链表分为两个部分进行递归排序。
3. **合并两个已排序的链表**：在合并两个链表时，我们按照大小顺序连接它们，确保结果仍然是有序的。

### 总结

- 通过使用归并排序，我们可以在 O(n log n) 的时间复杂度内对链表进行排序。
- 快慢指针帮助我们高效地找到链表的中点。
- 合并有序链表时，通过逐个节点比较来构建最终的排序链表。
