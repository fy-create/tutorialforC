[274. H 指数](https://leetcode.cn/problems/h-index)

Here is the content of the problem from Leetcode:

### 题目描述

给定一组整数，代表某个研究者的各篇论文被引用的次数。定义一个研究者的 H 指数为：有 h 篇论文分别被引用了至少 h 次，其余的论文被引用次数不超过 h 次。

请你计算该研究者的 H 指数。

### 示例 1

输入：`citations = [3, 0, 6, 1, 5]`  
输出：`3`  
解释：给定数组是研究者的引用次数 [3, 0, 6, 1, 5]。  
排序后数组是 [0, 1, 3, 5, 6]，  
该研究者有 3 篇论文的引用次数大于或等于 3，所以 H 指数是 3。

### 示例 2

输入：`citations = [1, 3, 1]`  
输出：`1`  
解释：排序后数组是 [1, 1, 3]，  
该研究者有 1 篇论文的引用次数大于或等于 1，所以 H 指数是 1。

### 提示

- n == citations.length
- 1 <= n <= 5000
- 0 <= citations[i] <= 1000

---

### 解题思路

H 指数的计算可以通过以下步骤：

1. **排序**：首先对引用次数数组进行排序，从大到小排列，这样就能让前面的论文引用次数较高。
2. **遍历排序后的数组**：然后遍历数组，找到一个最大的值 `h`，使得前 `h` 个元素的引用次数都大于等于 `h`。即，找出一个满足条件的最大 H 指数。
3. **实现细节**：我们可以使用简单的线性扫描来遍历排序后的数组，检查是否存在一个索引 `i`，使得 `citations[i] >= i + 1`。

### C 语言解答

```c
#include <stdio.h>
#include <stdlib.h>

// 比较函数，用于排序
int compare(const void *a, const void *b) {
    return *(int*)b - *(int*)a; // 从大到小排序
}

int hIndex(int* citations, int citationsSize) {
    // 对引用次数进行排序
    qsort(citations, citationsSize, sizeof(int), compare);
    
    // 遍历排序后的数组，找到 H 指数
    for (int i = 0; i < citationsSize; i++) {
        if (citations[i] < i + 1) {
            return i; // 找到第一个小于条件的返回前一个值
        }
    }
    
    return citationsSize; // 如果所有论文都符合条件，返回数组长度
}

int main() {
    int citations[] = {3, 0, 6, 1, 5};
    int size = sizeof(citations) / sizeof(citations[0]);
    printf("H-Index: %d\n", hIndex(citations, size));
    return 0;
}
```

### C++ 语言解答

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

class Solution {
public:
    int hIndex(vector<int>& citations) {
        // 对引用次数进行降序排序
        sort(citations.begin(), citations.end(), greater<int>());
        
        // 遍历排序后的数组，找到 H 指数
        for (int i = 0; i < citations.size(); i++) {
            if (citations[i] < i + 1) {
                return i; // 找到第一个小于条件的返回前一个值
            }
        }
        
        return citations.size(); // 如果所有论文都符合条件，返回数组长度
    }
};

int main() {
    Solution solution;
    vector<int> citations = {3, 0, 6, 1, 5};
    cout << "H-Index: " << solution.hIndex(citations) << endl;
    return 0;
}
```

这两个解法思路相同，只是语言不同。在 C 语言中，使用 `qsort` 函数进行排序，而在 C++ 中，使用 `sort` 函数，并且借助了 `greater<int>()` 来实现降序排列。
