[91. 解码方法](https://leetcode.cn/problems/decode-ways)

### 题目要求：

给定一个仅包含数字 `0-9` 的字符串 `s`，解码方式如下：
- 'A' -> "1", 'B' -> "2", ..., 'Z' -> "26"。
- 你需要返回这个字符串 `s` 的解码方法的总数。

**示例 1：**

```
输入：s = "12"
输出：2
解释：它可以解码为 "AB" (1 2) 或 "L" (12)。
```

**示例 2：**

```
输入：s = "226"
输出：3
解释：它可以解码为 "BBF" (2 2 6), "BF" (2 26) 或 "ZZ" (26 6)。
```

**示例 3：**

```
输入：s = "0"
输出：0
解释：没有有效的解码方式，因为没有对应的字母。
```

**提示：**
- `1 <= s.length <= 100`
- `s` 只包含数字，且不包含前导零。

### 解题思路：

这道题是一个典型的动态规划问题。我们需要找到一种方法来递归地分析每个位置可能的解码方式。

#### 动态规划解法：
1. **定义状态**：设 `dp[i]` 表示以第 `i` 个字符为结尾的字符串可以解码的总方法数。
2. **初始状态**：`dp[0] = 1`，表示空字符串有一种解码方法。
3. **转移方程**：
   - 如果当前位置的字符 `s[i-1]` 是一个有效的单字符解码（即它不是 '0'），那么可以从 `dp[i-1]` 过渡到 `dp[i]`。
   - 如果当前位置的字符和前一个字符 `s[i-2:i]` 组合在一起形成一个有效的两字符解码（即 `s[i-2]` 和 `s[i-1]` 组成一个 1-26 之间的数字），则可以从 `dp[i-2]` 过渡到 `dp[i]`。
4. **边界条件**：如果字符串以 `0` 开始，或者包含单独的 `0`，则没有有效的解码方式，返回 0。

### C语言解答：

```c
#include <stdio.h>
#include <string.h>

// 函数用于解码方式的计算
int numDecodings(char *s) {
    int n = strlen(s);
    
    // 如果字符串为空或第一个字符是'0'，返回0
    if (n == 0 || s[0] == '0') {
        return 0;
    }
    
    // dp[i]表示前i个字符的解码方式数
    int dp[n + 1];
    dp[0] = 1; // 空字符串有一种解码方式
    dp[1] = 1; // 如果字符串的第一个字符不是'0'，那么有一种解码方式
    
    for (int i = 2; i <= n; i++) {
        dp[i] = 0;
        
        // 检查当前字符是否可以单独作为一个解码（即不是'0'）
        if (s[i - 1] != '0') {
            dp[i] += dp[i - 1];
        }
        
        // 检查当前和前一个字符是否可以组成一个合法的数字
        int twoDigit = (s[i - 2] - '0') * 10 + (s[i - 1] - '0');
        if (twoDigit >= 10 && twoDigit <= 26) {
            dp[i] += dp[i - 2];
        }
    }
    
    return dp[n];
}

int main() {
    char s[] = "226";
    printf("解码方式总数: %d\n", numDecodings(s));
    return 0;
}
```

### C++解答：

```cpp
#include <iostream>
#include <vector>
#include <string>
using namespace std;

class Solution {
public:
    int numDecodings(string s) {
        int n = s.size();
        
        // 如果字符串为空或第一个字符是'0'，返回0
        if (n == 0 || s[0] == '0') {
            return 0;
        }
        
        // dp[i]表示前i个字符的解码方式数
        vector<int> dp(n + 1, 0);
        dp[0] = 1; // 空字符串有一种解码方式
        dp[1] = 1; // 如果字符串的第一个字符不是'0'，那么有一种解码方式
        
        for (int i = 2; i <= n; i++) {
            // 检查当前字符是否可以单独作为一个解码（即不是'0'）
            if (s[i - 1] != '0') {
                dp[i] += dp[i - 1];
            }
            
            // 检查当前和前一个字符是否可以组成一个合法的数字
            int twoDigit = (s[i - 2] - '0') * 10 + (s[i - 1] - '0');
            if (twoDigit >= 10 && twoDigit <= 26) {
                dp[i] += dp[i - 2];
            }
        }
        
        return dp[n];
    }
};

int main() {
    Solution sol;
    string s = "226";
    cout << "解码方式总数: " << sol.numDecodings(s) << endl;
    return 0;
}
```

### 代码解析：

#### C语言：
1. **字符串检查**：首先检查字符串的第一个字符是否是 '0'，如果是则直接返回 0，因为没有有效的解码方式。
2. **动态规划数组**：定义 `dp[i]` 表示前 `i` 个字符的解码方法数。初始化 `dp[0] = 1` 和 `dp[1] = 1`（前提是第一个字符不是 '0'）。
3. **动态转移**：对于每个位置 `i`，检查当前字符和前一个字符是否能构成有效的解码方式，并根据条件更新 `dp[i]`。
4. **输出结果**：最后返回 `dp[n]`，即解码方式的总数。

#### C++：
1. **字符串检查**：类似于 C 代码，先检查第一个字符是否是 '0'，若是则返回 0。
2. **动态规划数组**：使用 `vector<int>` 存储解码方式数。
3. **动态转移**：通过判断当前字符和前一个字符是否能构成有效的解码方式，更新 `dp[i]`。
4. **结果输出**：返回 `dp[n]`。

### 时间复杂度：
- **时间复杂度**：`O(n)`，其中 `n` 是字符串的长度。我们只需要遍历一遍字符串，并在每个位置进行常数时间的操作。
- **空间复杂度**：`O(n)`，用于存储 `dp` 数组。
