[191. 位1的个数](https://leetcode.cn/problems/number-of-1-bits)

### 题目要求

**题目名称：** Number of 1 Bits (汉字：二进制中1的个数)

**题目描述：**

编写一个函数，求给定的32位无符号整数的二进制中1的个数。

**示例1：**
输入: 00000000000000000000000000001011  
输出: 3  
解释: 输入的二进制串 00000000000000000000000000001011 中，共有 3 个 1。

**示例2：**
输入: 00000000000000000000000010000000  
输出: 1  
解释: 输入的二进制串 00000000000000000000000010000000 中，共有 1 个 1。

**示例3：**
输入: 11111111111111111111111111111101  
输出: 31  
解释: 输入的二进制串 11111111111111111111111111111101 中，共有 31 个 1。

**提示：**
- 输入必须是一个 32 位的无符号整数。

### 解题思路

本题要求计算32位无符号整数的二进制表示中1的个数。可以通过以下几种常见方法来解决：

1. **逐位检查法**：每次通过右移操作检查当前最低位是否为1，如果是1则计数加一，接着右移。直到整数变为0为止。时间复杂度是O(logN)，这里N是数字的大小，对于32位整数是固定的，所以是O(1)级别的。
  
2. **位运算优化法**：对于一个数x，我们可以通过`x & (x - 1)`操作消去x中最右边的1。例如，如果x=110100，`x - 1 = 110011`，`x & (x - 1)`结果是110000，右边的1被消去。每次执行此操作，就能消去一个1，直到所有1都被消去为止。该方法的时间复杂度为O(k)，其中k为数字x中1的个数。

我们采用第二种方法，因为它在实际中更高效。

### C语言解答

```c
#include <stdio.h>

// 函数：计算无符号整数中1的个数
int hammingWeight(unsigned int n) {
    int count = 0;
    // 使用位运算：每次消去最右边的1
    while (n) {
        n = n & (n - 1);  // 消去最右边的1
        count++;  // 增加1的计数
    }
    return count;
}

int main() {
    unsigned int num = 11;  // 示例输入
    printf("Number of 1 bits: %d\n", hammingWeight(num));  // 输出结果
    return 0;
}
```

### 代码解析：

1. `hammingWeight` 函数通过 `n = n & (n - 1)` 消去数字 `n` 中最右边的1，直到 `n` 变为0为止。
2. `count` 用来统计1的个数。
3. `main` 函数中调用 `hammingWeight`，传入一个示例值，并输出结果。

### C++ 解答

```cpp
#include <iostream>
using namespace std;

class Solution {
public:
    // 函数：计算无符号整数中1的个数
    int hammingWeight(uint32_t n) {
        int count = 0;
        // 使用位运算：每次消去最右边的1
        while (n) {
            n = n & (n - 1);  // 消去最右边的1
            count++;  // 增加1的计数
        }
        return count;
    }
};

int main() {
    Solution solution;
    uint32_t num = 11;  // 示例输入
    cout << "Number of 1 bits: " << solution.hammingWeight(num) << endl;  // 输出结果
    return 0;
}
```

### 代码解析：

1. `Solution` 类封装了 `hammingWeight` 函数，提供计算无符号整数中1的个数的功能。
2. `hammingWeight` 方法使用位运算消去每一个最右边的1，通过 `n = n & (n - 1)` 实现。
3. 在 `main` 函数中，我们创建 `Solution` 对象，并调用其 `hammingWeight` 方法。

### 总结

1. **时间复杂度：** 由于我们每次通过 `n = n & (n - 1)` 消去一个1，直到所有的1都消去，时间复杂度为O(k)，其中k是数字中1的个数。
2. **空间复杂度：** O(1)，因为我们只用了少量的额外空间。

通过使用位运算优化法，代码既简洁又高效。
