[190. 颠倒二进制位](https://leetcode.cn/problems/reverse-bits)

### 题目描述

颠倒给定的 32 位无符号整数的二进制位。

---

**示例 1：**

```
输入：n = 00000010100101000001111010011100
输出：964176192 (00111001011110000010100101000000)
解释：输入的二进制串 00000010100101000001111010011100 被颠倒后变为 00111001011110000010100101000000。
```

**示例 2：**

```
输入：n = 11111111111111111111111111111101
输出：3221225471 (10111111111111111111111111111111)
解释：输入的二进制串 11111111111111111111111111111101 被颠倒后变为 10111111111111111111111111111111。
```

---

**提示：**

- 输入是一个长度为 32 的二进制字符串

---

### 解题思路

1. **逐位处理**：
   - 将输入的整数 `n` 按位读取，每次取出最低位，将其放置到结果的相应位置。
   - 使用移位操作实现逐位读取和放置。

2. **操作步骤**：
   - 初始化结果为 `0`。
   - 遍历 32 位，对于每一位：
     - 将结果左移 1 位。
     - 将 `n` 的最低位加入结果。
     - 将 `n` 右移 1 位。
   - 最终结果即为颠倒后的数值。

3. **时间复杂度**：
   - 遍历 32 位，时间复杂度为 O(1)。

4. **空间复杂度**：
   - 使用常量空间，空间复杂度为 O(1)。

---

### C 语言实现

```c
#include <stdio.h>
#include <stdint.h>

// 颠倒 32 位无符号整数的二进制位
uint32_t reverseBits(uint32_t n) {
    uint32_t result = 0;
    for (int i = 0; i < 32; i++) {
        result <<= 1;         // 结果左移一位
        result |= (n & 1);    // 将 n 的最低位加入结果
        n >>= 1;             // n 右移一位
    }
    return result;
}

// 测试函数
int main() {
    uint32_t n = 43261596; // 00000010100101000001111010011100
    printf("输入: %u\n", n);
    uint32_t reversed = reverseBits(n);
    printf("颠倒后的结果: %u\n", reversed); // 964176192 (00111001011110000010100101000000)
    return 0;
}
```

### C++ 语言实现

```cpp
#include <iostream>
#include <cstdint>

using namespace std;

class Solution {
public:
    // 颠倒 32 位无符号整数的二进制位
    uint32_t reverseBits(uint32_t n) {
        uint32_t result = 0;
        for (int i = 0; i < 32; i++) {
            result <<= 1;         // 结果左移一位
            result |= (n & 1);    // 将 n 的最低位加入结果
            n >>= 1;             // n 右移一位
        }
        return result;
    }
};

// 测试函数
int main() {
    Solution sol;
    uint32_t n = 43261596; // 00000010100101000001111010011100
    cout << "输入: " << n << endl;
    uint32_t reversed = sol.reverseBits(n);
    cout << "颠倒后的结果: " << reversed << endl; // 964176192 (00111001011110000010100101000000)
    return 0;
}
```

### 代码说明

1. **逐位读取和放置**：
   - 通过 `n & 1` 获取最低位，将其放置到 `result` 的最低位。
   - 使用移位操作动态调整位置。

2. **时间复杂度**：
   - 固定处理 32 位，时间复杂度为 O(1)。

3. **空间复杂度**：
   - 使用常量空间，空间复杂度为 O(1)。
