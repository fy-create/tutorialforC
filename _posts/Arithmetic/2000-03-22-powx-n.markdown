[50. Pow(x, n)](https://leetcode.cn/problems/powx-n)

### 题目描述：
实现 `pow(x, n)` ，即计算 x 的 n 次幂函数（即，`x^n`）。

**示例：**

**输入：** x = 2.00000, n = 10

**输出：** 1024.00000

**输入：** x = 2.10000, n = 3

**输出：** 9.26100

**输入：** x = 2.00000, n = -2

**输出：** 0.25000

**提示：**
- -100.0 < x < 100.0
- -2^31 <= n <= 2^31-1
- -10^4 <= x^n <= 10^4

---

### 解题思路：

1. **快速幂法：**
   - 快速幂是一种优化计算幂的算法，通过不断将指数减半、基数平方来减少计算量。
   - 如果 n 是偶数：`x^n = (x^2)^(n/2)`。
   - 如果 n 是奇数：`x^n = x * (x^2)^((n-1)/2)`。

2. **递归或迭代实现：**
   - 递归实现更直观，但可能会有栈溢出的风险。
   - 迭代实现不需要额外的递归栈，更加高效。

3. **处理负指数：**
   - 如果 n 是负数，将其转为正数并取倒数：`x^(-n) = (1/x)^n`。

4. **时间复杂度：**
   - 快速幂算法的时间复杂度为 O(log n)。

5. **空间复杂度：**
   - 递归实现的空间复杂度为 O(log n)，迭代实现的空间复杂度为 O(1)。

```c
#include <stdio.h>

double myPow(double x, int n) {
    if (n == 0) return 1.0; // 任何数的 0 次幂为 1
    long long N = n; // 使用 long long 防止溢出
    if (N < 0) {
        x = 1 / x;
        N = -N;
    }
    double result = 1.0;
    while (N > 0) {
        if (N % 2 == 1) {
            result *= x; // 如果指数是奇数，乘一次当前的 x
        }
        x *= x; // 基数平方
        N /= 2; // 指数减半
    }
    return result;
}

int main() {
    double x = 2.0;
    int n = 10;
    printf("%f\n", myPow(x, n)); // 输出 1024.000000

    x = 2.1;
    n = 3;
    printf("%f\n", myPow(x, n)); // 输出 9.261000

    x = 2.0;
    n = -2;
    printf("%f\n", myPow(x, n)); // 输出 0.250000

    return 0;
}
```

#include <iostream>
using namespace std;

class Solution {
public:
    double myPow(double x, int n) {
        if (n == 0) return 1.0; // 任何数的 0 次幂为 1
        long long N = n; // 使用 long long 防止溢出
        if (N < 0) {
            x = 1 / x;
            N = -N;
        }
        double result = 1.0;
        while (N > 0) {
            if (N % 2 == 1) {
                result *= x; // 如果指数是奇数，乘一次当前的 x
            }
            x *= x; // 基数平方
            N /= 2; // 指数减半
        }
        return result;
    }
};

int main() {
    Solution sol;
    cout << sol.myPow(2.0, 10) << endl; // 输出 1024.0
    cout << sol.myPow(2.1, 3) << endl;  // 输出 9.261
    cout << sol.myPow(2.0, -2) << endl; // 输出 0.25
    return 0;
}
