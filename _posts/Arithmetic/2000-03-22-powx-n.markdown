[50. Pow(x, n)](https://leetcode.cn/problems/powx-n)

### 题目描述

实现 `pow(x, n)`，即计算 x 的 n 次幂（即，xⁿ）。

**示例 1：**

```
输入：x = 2.00000, n = 10
输出：1024.00000
```

**示例 2：**

```
输入：x = 2.10000, n = 3
输出：9.26100
```

**示例 3：**

```
输入：x = 2.00000, n = -2
输出：0.25000
解释：2⁻² = 1/(2²) = 1/4 = 0.25
```

**提示：**

- `-100.0 < x < 100.0`
- `-2³¹ <= n <= 2³¹ - 1`
- `n` 是一个整数
- 要么 `x` 不为零，要么 `n` 为正整数
- `-10⁴ <= xⁿ <= 10⁴`

**解题思路：**

为了高效地计算 x 的 n 次幂，可以使用**快速幂算法**（也称为**二分幂算法**），其时间复杂度为 O(log n)。该算法利用以下数学性质：

- 当 n 为偶数时，xⁿ = (x²)^(n/2)
- 当 n 为奇数时，xⁿ = x * x^(n-1)

通过递归地将问题规模减半，可以显著减少计算次数。需要注意处理 n 为负数的情况，此时 xⁿ = 1 / x⁻ⁿ。

**C 语言实现：**

```c
#include <stdio.h>

// 计算 x 的 n 次幂的函数
double myPow(double x, int n) {
    // 处理 n 为最小负值的特殊情况
    if (n == -2147483648) {
        return 1.0 / (myPow(x, 2147483647) * x);
    }
    // 如果 n 为负数，将 x 取倒数，n 取相反数
    if (n < 0) {
        x = 1 / x;
        n = -n;
    }
    double result = 1.0;
    // 快速幂算法
    while (n > 0) {
        // 如果 n 是奇数，将当前的 x 乘到结果中
        if (n % 2 == 1) {
            result *= x;
        }
        // 将 x 平方，n 减半
        x *= x;
        n /= 2;
    }
    return result;
}

// 测试函数
int main() {
    double x = 2.0;
    int n = 10;
    printf("Result: %f\n", myPow(x, n)); // 输出：1024.000000
    return 0;
}
```

**C++ 语言实现：**

```cpp
#include <iostream>

using namespace std;

class Solution {
public:
    // 计算 x 的 n 次幂的函数
    double myPow(double x, int n) {
        // 处理 n 为最小负值的特殊情况
        if (n == INT_MIN) {
            return 1.0 / (myPow(x, INT_MAX) * x);
        }
        // 如果 n 为负数，将 x 取倒数，n 取相反数
        if (n < 0) {
            x = 1 / x;
            n = -n;
        }
        double result = 1.0;
        // 快速幂算法
        while (n > 0) {
            // 如果 n 是奇数，将当前的 x 乘到结果中
            if (n % 2 == 1) {
                result *= x;
            }
            // 将 x 平方，n 减半
            x *= x;
            n /= 2;
        }
        return result;
    }
};

// 测试函数
int main() {
    Solution sol;
    double x = 2.0;
    int n = 10;
    cout << "Result: " << sol.myPow(x, n) << endl; // 输出：1024.00000
    return 0;
}
```

上述代码实现了快速幂算法，能够高效地计算 x 的 n 次幂。需要特别注意处理 n 为负数的情况，以及避免整数溢出。
