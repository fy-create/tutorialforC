[319. 灯泡开关](https://leetcode.cn/problems/bulb-switcher)

### 题目：**Bulb Switcher**

#### 题目描述：

有 `n` 个灯泡排成一列，编号为 `1` 到 `n`。初始时，所有灯泡的状态为关闭。

对于每一次操作，您可以选择从灯泡编号 `1` 到 `n` 中的任意一个灯泡 `k`，并切换 `k` 及其所有后续灯泡的状态（包括 `k` 自己）。即：
- 如果一个灯泡是关闭的，它会被打开；
- 如果一个灯泡是打开的，它会被关闭。

对于给定的 `n`，需要返回在执行完所有操作之后，最终灯泡的开启状态有多少个。

**示例 1：**
```plaintext
输入: n = 3
输出: 1
解释:
按以下顺序执行操作:
第一次操作, 选择灯泡 1，所有灯泡状态变为: [开, 开, 开]
第二次操作, 选择灯泡 2，所有灯泡状态变为: [开, 关, 开]
第三次操作, 选择灯泡 3，所有灯泡状态变为: [开, 关, 关]
最终只有灯泡 1 是开着的。
```

**示例 2：**
```plaintext
输入: n = 4
输出: 2
解释:
按以下顺序执行操作:
第一次操作, 选择灯泡 1，所有灯泡状态变为: [开, 开, 开, 开]
第二次操作, 选择灯泡 2，所有灯泡状态变为: [开, 关, 开, 开]
第三次操作, 选择灯泡 3，所有灯泡状态变为: [开, 关, 关, 开]
第四次操作, 选择灯泡 4，所有灯泡状态变为: [开, 关, 关, 关]
最终灯泡 1 和 4 是开着的。
```

**提示：**
- `1 <= n <= 1000`

---

### 解题思路：

#### 1. **分析灯泡状态变化：**
   - 每个灯泡的状态变化会根据其编号的奇偶性而不同。每次选择一个灯泡 `k`，会将灯泡 `k` 和所有大于 `k` 的灯泡状态切换。
   - 第一次操作会改变所有灯泡的状态，第二次操作会从第二个灯泡开始改变，第三次操作从第三个灯泡开始改变，以此类推。

#### 2. **观察规律：**
   - 如果灯泡的编号是奇数，经过所有操作后，灯泡的状态是开（开关次数为奇数）。
   - 如果灯泡的编号是偶数，经过所有操作后，灯泡的状态是关（开关次数为偶数）。
   
   因此，最终开着的灯泡的个数就是编号为 **完全平方数** 的灯泡的个数。因为一个灯泡编号的操作次数是奇数当且仅当该编号是完全平方数。

#### 3. **如何计算结果：**
   - 要找到 `1` 到 `n` 中所有完全平方数的数量，实际上就是计算 `1^2`, `2^2`, ..., `k^2` 中小于等于 `n` 的数，其中 `k` 是最大的整数，满足 `k^2 <= n`。那么 `k` 就是 `n` 的平方根的整数部分。

#### 4. **时间复杂度：**
   - 计算 `n` 的平方根是一个 O(1) 操作。

---

### C语言解答：

```c






#include <stdio.h>
#include <math.h>

// 函数：返回n的平方根的整数部分
int bulbSwitch(int n) {
    // 计算 n 的平方根，并取整
    return (int)sqrt(n);
}

int main() {
    int n = 3;
    printf("The number of bulbs that are on: %d\n", bulbSwitch(n));
    return 0;
}
```

### C++ 解答：

```cpp
#include <iostream>
#include <cmath>
using namespace std;

class Solution {
public:
    // 函数：返回n的平方根的整数部分
    int bulbSwitch(int n) {
        return (int)sqrt(n); // 计算 n 的平方根并取整
    }
};

int main() {
    Solution sol;
    int n = 3;
    cout << "The number of bulbs that are on: " << sol.bulbSwitch(n) << endl;
    return 0;
}
```

### 代码解释：

1. **C语言解答：**
   - 使用 `sqrt` 函数来计算 `n` 的平方根。
   - `int` 类型强制转换将得到平方根的整数部分，这就代表了最终状态为 "开" 的灯泡个数。

2. **C++ 解答：**
   - 在 `Solution` 类中定义了 `bulbSwitch` 方法，计算平方根并返回整数部分，表示最终开着的灯泡数量。

### 总结：
- **时间复杂度**：O(1)，计算平方根的复杂度是常数时间。
- **空间复杂度**：O(1)，只需要常量空间。

这个问题通过观察规律，可以在 O(1) 时间内计算出最终的结果。
